# Niraiva OnCoTrack Demo Dataset

This folder documents the oncology demo data generated by `scripts/seed-oncology-demo.mjs`.

The seed creates four synthetic, original patient journeys for investor and clinician demonstration:

1. Stage I breast cancer: screening mammogram, biopsy, receptor status, lumpectomy, radiation, endocrine therapy, surveillance.
2. Stage II prostate cancer: PSA velocity, MRI, biopsy, radiation, short-course ADT, PSA response monitoring.
3. Stage III lung adenocarcinoma: smoking-history screening eligibility, symptoms, LDCT/PET-CT, biopsy, chemoradiation, consolidation immunotherapy.
4. Stage IV colorectal cancer: anemia, positive FIT, colonoscopy, CEA trend, liver metastasis, systemic therapy, response monitoring.

Each case covers at least one year before diagnosis and one year after diagnosis. The data is synthetic and designed for demonstration only. It is not copied from a real patient record and must not be used as medical guidance.

Run:

```bash
node scripts/seed-oncology-demo.mjs
```
